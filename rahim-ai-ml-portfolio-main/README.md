# Rahim Hassan — AI/ML Portfolio

Static portfolio website for MD Rahim Hassan Sarniabath.

## Included

- AI/ML-focused hero section
- Skills
- Featured projects
- Automatic display of ALL public GitHub repositories
- Bangla hate-speech research section
- Contact email
- GitHub, Kaggle and Hugging Face links
- Responsive design

## Important

The "All Public GitHub Projects" section fetches repositories directly from:

https://github.com/phitron-rahim

So new public repositories will automatically appear after deployment.

## Deploy

### Vercel
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to Vercel and import the GitHub repository.
4. Deploy.

No build command is required.
